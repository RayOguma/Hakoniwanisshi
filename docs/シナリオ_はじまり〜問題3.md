- (2026-10-08)**`:` と `;` の書き方は、せりふではなく解説サイトで教える**: 解説サイトのいちばん上に「はじめに:CSS の書き方の基本」(HTML と CSS の役割、`.box { }` の形、`名前: 値;`、`:` と `;` を忘れると効かないこと、`/* */` のメモ)。主人公は、まずそれを読んで「書き方は『名前: 値;』……」「ふーん。これも、あとで役に立つかもな」→ 下へ送って opacity の記事を見つける →「……あった。透け具合を変えるのが『opacity』」
- (2026-10-08)**行の書き足しは、Enter でも、ほかの所をクリックしても決まる**。鍵のかかった行と同じ名前(たとえば `animation: paused;`)を書き足すと、「鍵がかかっているみたい」と知らせて、書き換えない
- (2026-10-08)**プレイヤーが自分でクリックする番は、カーソルで知らせる**: 検索結果の「箱庭日誌」が黄色く光っているあいだ、カーソルのまわりに黄色い輪が脈打つ。光っている所に乗せると輪が大きく濃くなり、クリックすると輪がはじけて消える。**同じ合図を、ほかの「はじめての操作」にも使う**: ①はじめて住人に話しかけるとき(「!」の `v` に合わせて輪が大きくなる)②解説サイトの検索結果(主人公の自動クリックはやめ、プレイヤーがクリックする。検索語の入力は自動のまま)②'はじめて「ソースを見る」を押すとき(ボタンが黄色く光る)③はじめてのタブ移動(解説サイトを読んだあと、「箱庭日誌」のタブが黄色く光り、プレイヤーが押して戻る。自動では戻らない)。これで操作のしかたは、だいたい分かるはず
- (2026-10-08)**問題3は、`v` に「!」がつき、`v` に話しかけると始まる**(`v` が「ワーカー! おてがみ ある?」と話し始めるイベントなので。ワーカーは速くてクリックしにくいが、ずっと走っているのはそのまま)
- (2026-10-08)~~ワーカーを止めたとき、見えないところにいたら、見えるところまで走ってきてから止まる~~ → **やめた**(しゃべる子に画面が寄るようになったので、いらない)。ワーカーは、止めた所でそのまま止まる
- (2026-10-08)**会話は、ソースのパネルを閉じてから流す**(書き換えたあとの反応・問題が解けたとき・問題を始めるとき)。パネルを開くとページが横にずれ、住人の位置と演出(雨など)がずれて分かりにくいため。**パネルが開いていたなら、会話のあとで開き直す**(問題を始めるとき・まだ直すところがある反応のとき。**問題が解けたあとは、次の問題を探しに行くので開き直さない**)。会話のあいだは「ソースを見る」を押しても開かない。ページの幅が変わったときは、住人もページといっしょに横へ動く

## 6. 書き換えたときの反応(例)
