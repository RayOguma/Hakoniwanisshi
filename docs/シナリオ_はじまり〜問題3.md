## 4. 問題3:配達係ワーカーが止まらない

**関わる住人**: ワーカー・`v`・エコー(手紙の送り主として名前だけ)
**仕掛け**: 時を止める(`animation-play-state`)

### できごと
ワーカーは、ひろばの左右を、笑いながら走り続けている。手には手紙。

> ・v・「ワーカー！ ねえ、ぼくに おてがみ ある？」
> ・w・「あはは！ あるよー！ あるけど、とまれないのー！」
> ・v・「とまって！」
> ・w・「とまりかた、しらないのー！ あはははは！」
> ・v・「……かんりにんさん、ワーカー とめて！」

### ソース
ワーカーのところに、ワーカーの日記と、管理人の書き忘れのメモがある。

```html
<!-- 2009/05/20
  w がまた笑っている。何がおかしいのか聞いたら、余計に笑った。
  バグではない。仕様だ。 -->
```

```css
.w {
  animation: run 1.2s linear infinite;
  /* 止める処理を書き忘れた。まあいい、楽しそうだし */
}
```

- `animation-play-state: paused;` を書き足す(はじめて、自分で一行書く問題)
- ヒント(企画書 5.2): 問題が出るときは、`v` は「ワーカー とめて！」と、何をしたいかだけを言う。話しかけると、それぞれのやり方で手伝う
  - ・v・「とまって、って かくんだよ、きっと！」(方向だけ)
  - ・l・「任せろ。止まらないなら、もっと速く走らせればいい。そのうち疲れて止まる」(ずれている)
  - ・u・「……とまるのは……ポーズ……ぐう」(寝言で核心)
  - -h-「……`animation-play-state` だ。……止めるなら、`paused`」(ほとんど答え)
  - 解説タブ: 「アニメーションを止める」の項目に、`animation-play-state: paused;` の説明と例が載る
- 📝 書く形をどこまで手伝うか(候補から選ぶ/一部を打つ)

### 直したあと
> ・w・「……とまった！ あはは、とまれた！ とまるって、たのしいね！」
> ・v・「おてがみ！ おてがみ！」
> ・w・「はい！ ……あれ、これ、`v` のじゃないや。エコーから、マージへの おてがみだ」
> ・v・「マージ？ マージって、川の むこうの？」
> ・w・「そう！ ずっと わたそうとしてたんだけど、川があって、むこうに いけないの。だから ずっと はしってた！」
> ・v・「……エコーと マージ、ずっと あえてないの？」
> ・w・「うん。おてがみだけ。ぼくが いるから、だいじょうぶ！ あはは！」

- ワーカーの手紙が、エコーとマージの唯一のつながりだった(問題4へ)
- 止まったワーカーは、プレイヤーがまた動かせる(`paused` を消すと、また走る)。走らせると「あはは！ やっぱり はしるのも たのしい！」。手紙を渡し終えたあとは、走っていても止まっていてもよい
- **開く場所**: ひろばの下の「工事中」が一つ外れて、川が見えるようになる(問題4へ)

## 6. 書き換えたときの反応(例)

開いた場所は、いつでも書き換えられる(企画書 5.2)。住人が反応する例:
