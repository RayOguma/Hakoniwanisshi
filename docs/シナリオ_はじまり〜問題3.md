### ソース
ワーカーのところに、ワーカーの日記と、管理人の書き忘れのメモがある。

```html
<!-- 2009/05/20
  w がまた笑っている。何がおかしいのか聞いたら、余計に笑った。
  バグではない。仕様だ。 -->
```

```css
.w {
  animation: run 1.2s linear infinite;
  /* 止める処理を書き忘れた。まあいい、楽しそうだし */
}
```

- `animation-play-state: paused;` を書き足す(はじめて、自分で一行書く問題)
- ヒント(企画書 5.2): 問題が出るときは、`v` は「ワーカー とめて！」と、何をしたいかだけを言う。話しかけると、それぞれのやり方で手伝う
  - ・v・「とまって、って かくんだよ、きっと！」(方向だけ)
  - ・l・「任せろ。止まらないなら、もっと速く走らせればいい。そのうち疲れて止まる」(ずれている)
  - ・u・「……とまるのは……ポーズ……ぐう」(寝言で核心)
  - -h-「……`animation-play-state` だ。……止めるなら、`paused`」(ほとんど答え)
  - 解説タブ: 「アニメーションを止める」の項目に、`animation-play-state: paused;` の説明と例が載る
- 📝 書く形をどこまで手伝うか(候補から選ぶ/一部を打つ)

## 6. 書き換えたときの反応(例)

開いた場所は、いつでも書き換えられる(企画書 5.2)。住人が反応する例:

- `v` の `opacity` を、また下げる → ・v・「やだ！ すけちゃう！ もどして！」
- `v` の `color` を変える → ・v・「わあ、ぼく、○○いろだ！」(色の名前は、近い色から)
