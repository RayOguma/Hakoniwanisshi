# 箱庭日誌 〜定年エンジニアの手作りページ〜

古い個人ホームページに住む、小さな住人たちと話しながら、ページのソース(HTML・CSS)を書き換えて、こわれた所を直していくゲームです。お話を読むのが中心の、謎解きゲームです。

HTML や CSS を知らなくても遊べます。書き方は、ゲームの中で主人公といっしょに調べていきます。

- 遊ぶ時間の目安: 1時間半〜2時間(とちゅうでセーブできます)
- 遊ぶ環境: パソコンのブラウザ(Chrome か Edge)。マウスとキーボードを使います。スマートフォンには、まだ合わせていません
- 音は、まだ ありません

> いまは、テストプレイ用の試作版です。タイトル画面の絵は、仮のものです。

## 遊ぶ準備

[Node.js](https://nodejs.org/)(22 以上)がいります。

```
git clone https://github.com/RayOguma/Hakoniwanisshi.git
cd Hakoniwanisshi
npm install
npm run dev
```

ブラウザで http://localhost:5174 を開くと、タイトル画面が出ます。

`npm run dev` で開くと、タイトル画面に「開発用：」という欄が出ます。これは、とちゅうの問題から始めるための、作る人向けの欄です。はじめて遊ぶときは「はじまりから」のまま、「はじめる」を押してください。

## 遊び方

| すること | やり方 |
|---|---|
| 会話を進める | クリック・スペース・Enter で、次のせりふへ進みます。会話の窓の右上の「ログ」で、これまでの会話を見返せます |
| 住人と話す | ページの中を歩いている住人を、クリックします。頭の上に「!」が出ている子に話しかけると、お話が進みます |
| ページを直す | 右上の「ソースを見る」(S キー)で、ページのソースが開きます。CSS の値をクリックして書き換えると、ページがすぐに変わります |
| 行を書き足す | 「＋ 行を書き足す」の欄には、「名前: 値;」の形で、新しい行を書き足せます。書き足した行は × で消せます |
| 元に戻す | 書き換えて分からなくなったら、場所ごとの「元に戻す」で、はじめの形に戻せます |
| ほかのページを見る | 画面の上のタブで、検索のページや、解説のページに切りかえられます |
| セーブ | 右上の「メニュー」→「セーブ」。タイトル画面の「つづきから」で、続きから遊べます(会話のあいだは、セーブできません) |

### こまったときは

- 住人に話しかけると、その子なりのヒントをくれます。ヘッド(`-h-`)は、ほとんど答えを教えてくれます
- 「やさしいHTML・CSS入門」のタブに、書き方の説明があります
- ソースの中の緑色の字は、このページを作った人の日記です。新しい場所が開くたびに、読めるようになります

### セーブについて

セーブは、遊んでいるブラウザの中に、1つだけ記録されます。ブラウザの閲覧データを消すと、セーブも消えます。別のブラウザや、別のパソコンには引きつげません。

## テストプレイをしてくださる方へ

**`docs/` と `src/story.ts` には、お話の結末まで書いてあります。遊び終わるまで、開かないことをおすすめします。**

気づいたことは、どんなに小さなことでも うれしいです。とくに、次のような所を教えてください。

- どこで手が止まったか(何をすればいいか、分からなくなった所)
- 分かりにくかった せりふや、説明
- 動きが おかしかった所(できれば、どの場面で、何をしたときか)
- 長く感じた所、たいくつだった所
- 遊び終わって、どう感じたか

## 作る人向け

- `npm run dev` — 開発サーバー(http://localhost:5174)
- `npm run build` — 型チェックと、ビルド(`dist/` にできます)
- 企画は `docs/企画書.md`、決まったことは `docs/シナリオ_はじまり〜問題3.md` にまとめてあります(どちらも、結末まで書いてあります)
